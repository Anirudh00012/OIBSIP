1. Introduction:
The Travel Explorer Website is a modern, responsive landing page designed for a travel and tourism business. It is developed using core web technologies including HTML, CSS, and JavaScript, and presents an attractive interface for showcasing travel destinations, packages, and services.

    topBtn.style.display = "block";

});

topBtn.addEventListener("click", () => {
  window.scrollTo({ top: 0, behavior: "smooth" });

Project Title: Temperature Converter Website using HTML, CSS, and JavaScript

Developed By:

📖 Introduction

The Temperature Converter Website is a simple and interactive web application designed to convert temperature values between Celsius (°C), Fahrenheit (°F), and Kelvin (K). The project is developed using core web technologies including HTML, CSS, and JavaScript.

The primary objective of this project is to provide users with a fast, accurate, and user-friendly temperature conversion tool. Users can enter a temperature value, select the source unit and target unit, and instantly view the converted result.

The application features input validation, responsive design, animated UI elements, and real-time conversion calculations. This project demonstrates the practical implementation of JavaScript logic, DOM manipulation, form validation, and modern UI design principles.

🎯 Project Objectives:
To develop a temperature conversion system using web technologies.
To perform accurate conversions between Celsius, Fahrenheit, and Kelvin.
To implement input validation for improved user experience.
To create a responsive and visually appealing user interface.
To enhance understanding of JavaScript event handling and DOM manipulation.
To apply HTML, CSS, and JavaScript concepts in a real-world project.

✅ Project Outcomes:

Module 3 – Temperature Conversion Module
Purpose:
Perform temperature calculations based on selected units.

Conversion Formulas:

Celsius to Fahrenheit
°F = (°C × 9/5) + 32

Celsius to Kelvin
K = °C + 273.15

Fahrenheit to Celsius
°C = (°F − 32) × 5/9

Fahrenheit to Kelvin
K = ((°F − 32) × 5/9) + 273.15

Kelvin to Celsius
°C = K − 273.15

Kelvin to Fahrenheit
°F = ((K − 273.15) × 9/5) + 32

Module 4 – Result Display Module
Purpose:
Display converted temperature.

Output Format:
✅ 98.60 °F

Features:

Displays converted value with proper unit symbol.
Shows conversion result instantly.

Module 5 – Input Validation Module
Purpose:
Ensure user enters valid temperature values.

Validation Rules
Empty input not allowed.
Non-numeric values rejected.
Error Message
❌ Please enter a valid number

Module 6 – Reset Module
Purpose
Reset all fields to default values.

Functions:

Clears temperature input.
Resets dropdown selections.
Clears result display.
